# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of the project.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

If you are using an older version, please update to the latest release before reporting a vulnerability whenever possible.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not publicly disclose the vulnerability through a GitHub Issue.**

Instead, please use GitHub's private vulnerability reporting feature, if available for this repository.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* The affected version
* Any relevant screenshots, logs, or proof-of-concept information

Please provide as much detail as possible so the issue can be investigated efficiently.

### What to Expect

After receiving a vulnerability report, I will review it as soon as reasonably possible.

If the vulnerability is confirmed:

* The issue will be investigated and prioritized.
* A fix may be developed and released.
* The vulnerability may be documented after a fix is available.

If the report is determined not to be a security vulnerability, you may be informed of the reasoning.

Please allow reasonable time for investigation and remediation before publicly disclosing the vulnerability.

## Responsible Disclosure

Please avoid publicly sharing details that could allow others to exploit a vulnerability before a fix is available.

Thank you for helping keep this project and its users secure.
