# Contributing

Thank you for your interest in contributing to this project!

I appreciate bug reports, feature suggestions, feedback, and other forms of community involvement.

## Important: No Pull Requests

This project **does not accept Pull Requests**.

Please do **not** open a Pull Request to submit code, fixes, features, or other changes.

All contributions should be submitted through **GitHub Issues**.

## How to Contribute

### 🐛 Report a Bug

If you find a bug, please open an Issue and include:

* A clear description of the problem
* Steps to reproduce it
* What you expected to happen
* What actually happened
* Relevant screenshots or error messages, if applicable
* Your operating system, browser, or environment when relevant

### 💡 Suggest a Feature

Feature suggestions are welcome.

When opening an Issue, please explain:

* What you would like to see
* Why the feature would be useful
* How you think it could work, if you have an idea

### 💬 General Feedback

You can also use Issues to:

* Report unexpected behavior
* Suggest improvements
* Discuss potential features
* Point out usability problems
* Share ideas or feedback about the project

## Before Opening an Issue

Before creating a new Issue, please check the existing Issues to make sure the topic has not already been reported or discussed.

This helps keep the project organized and prevents duplicate discussions.

## Code Contributions

Code contributions through Pull Requests are not accepted.

If you have a code fix or implementation idea, you are welcome to describe it in an Issue. I may review the suggestion and implement it myself.

Please do not submit a Pull Request unless the project owner has explicitly requested one.

## Respectful Discussions

Please keep discussions respectful and constructive.

Different opinions and approaches are welcome, but personal attacks, harassment, spam, or unrelated content are not.

## Thank You ❤️

Thank you for taking the time to report issues, suggest improvements, and help make the project better.

Even if your contribution is only an Issue, your feedback is valuable and appreciated.
